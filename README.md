# Shuying Li — academic homepage

A bilingual (English / 中文) personal academic page. Single self-contained
`index.html`: no build step, no dependencies, no external assets.

- **Research:** dialogic teaching, teacher education, comparative and
  international education, sociology of education.
- **Language:** switches on the button in the header; defaults to the
  browser's language.
- **Theme:** follows the operating system, with a manual override.
- **Type:** Times New Roman for English, Songti for Chinese, Kaiti for the
  thesis pull-quote.

Open `index.html` in any browser, or serve the folder statically.
